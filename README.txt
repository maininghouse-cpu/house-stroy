HOUSE STROY — сайт с админ-панелью управления проектами.

ЗАПУСК НА MAC:
1. Распакуйте архив.
2. Откройте папку house-stroy-admin-full.
3. Дважды нажмите start-local.command (если macOS спросит разрешение, разрешите запуск).
4. Откройте http://localhost:8000
5. Админ-панель: http://localhost:8000/admin.html

ЗАПУСК НА WINDOWS:
Дважды нажмите start-local.bat, затем откройте http://localhost:8000

ВОЗМОЖНОСТИ АДМИН-ПАНЕЛИ:
- Добавление, редактирование и удаление проектов.
- Стоимость, общая и жилая площадь, этажность, спальни, описание.
- Обложка проекта и перетаскивание нескольких изображений в разделы 3D, Планы, Фасады и дополнительные фото.
- Просмотр проекта по клику на карточку; увеличение изображений.
- Фильтр каталога по площади, цене и этажности.
- Экспорт и импорт каталога JSON для резервного копирования.

ВАЖНО:
Данные сохраняются локально в браузере на этом компьютере. Это демонстрационная автономная админка: она не публикует изменения на внешнем хостинге и не синхронизирует их между устройствами. Для этого потребуется серверная база данных и авторизация. Не очищайте данные браузера без предварительного экспорта JSON. Изображения сохраняются в локальном хранилище браузера; для стабильной работы загружайте оптимизированные фотографии разумного размера.
